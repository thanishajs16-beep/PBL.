# Priority Scheduling — Student 2

## Algorithms Implemented
1. Non-preemptive Priority Scheduling
2. Preemptive Priority Scheduling

## Features
- Process ID, Arrival Time, Burst Time and Priority
- Gantt chart generation
- Completion Time (CT)
- Turnaround Time (TAT)
- Waiting Time (WT)
- Response Time (RT)
- Average scheduling metrics

## Priority Convention
A smaller priority number represents a higher priority.

## Compilation and Execution
```bash
gcc -Wall -Wextra -std=c11 priority.c test_priority.c -o test_priority
./test_priority
```
